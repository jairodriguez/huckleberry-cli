# Landing Page Architecture Reference

## Source Attribution

This architecture synthesizes:

- **Boringmarketer's 8-section structure** (Hero, Success, Problem-Agitate, Value Stack, Social Proof, Transformation, Secondary CTA, Footer)
- **Our existing skills:** `/copywriting` (page structure, CTA formulas), `/direct-response-copy` (headlines, So What? Chain, pain quantification, scoring rubric), `/page-cro` (5-second test, CTA audit, social proof audit, objection handling), `/positioning-angles` (awareness levels, angle generators, competitive landscape)
- **New additions not in any existing skill:** Value Stack section (Hormozi Grand Slam Offer), Transformation Roadmap (4-stage outcome ladder), Success/confirmation section (post-conversion experience)

## The 8 Sections — Quick Reference

| # | Section | Job | Key Metric |
|---|---------|-----|------------|
| 1 | Hero | Get email or get scroll | Click-through rate on primary CTA |
| 2 | Success | Kill buyer's remorse | Post-opt-in engagement rate |
| 3 | Problem-Agitate | Make status quo painful | Scroll depth past this section |
| 4 | Value Stack | Make saying no feel stupid | Price-to-value perception |
| 5 | Social Proof | Let others convince them | Trust score / testimonial engagement |
| 6 | Transformation | Make outcome tangible | Desire / "I want that" response |
| 7 | Secondary CTA | Catch the scrollers | Secondary CTA click rate (30-50% of total) |
| 8 | Footer | Professional legitimacy | Trust signals present |

| Capability | Before (Fragmented) | After (This Skill) |
|-----------|---------------------|---------------------|
