# Link Building for New Websites

A complete, ordered framework for building authority and backlinks on a brand new domain. Based on Jesper Nissen's proven method. Follow these steps **in order** — each step builds on the previous one.

**Target audience:** Local businesses, SaaS, blogs, low-to-medium competition keywords. NOT for high-competition niches like iGaming.

**Timeline:** All 7 steps can be completed in ~2 weeks. Doing all of them puts you ahead of 95% of competitors.

---

## Step 0: Google Business Profile (GBP)

**Do this first.** The GBP is the authority hub Google trusts most.

1. Create or claim the GBP
2. Fill in ALL business info — name, address, phone, website, hours, categories
3. Add ALL social media profile URLs (steps 1-7 profiles go here)
4. Create GBP posts with outgoing links to website content and videos

**Why:** Google uses GBP as a trust signal. Posts with links pass authority. GBP links appear in knowledge panels and AI overviews.

---

## Step 1: Core Social Profiles

Build these 7 profiles (the ones GBP recommends). Each should link back to the website AND cross-link to other social profiles.

| # | Platform | Link to Website | Link in Posts |
|---|----------|:-:|:-:|
| 1 | YouTube | Y | Y |
| 2 | Facebook | Y | Y |
| 3 | LinkedIn | Y | Y |
| 4 | Pinterest | Y | Y |
| 5 | X (Twitter) | Y | Y |
| 6 | Instagram | Y (bio) | N |
| 7 | TikTok | Y (bio) | N |

**Additional profiles to build:** Threads, Bluesky

**Rules:**
- Use consistent brand name, logo, bio across all
- Add website URL in every profile's "link" field
- Cross-link between profiles where possible
- Add all profile URLs back into GBP

## Step 2: Citations (NAP Consistency)

Citations are directory listings with consistent Name-Address-Phone info. Low individual power but critical for local SEO and increasingly important for AI overviews (Gemini, ChatGPT cite directories).

**How to build:**
- Order citation packages on Fiverr or Legiit (search "citations")
- Pick the cheapest options — quality is similar across providers
- Ensure NAP is **identical** across every citation
- Include short business description + link to socials in each

**Why it matters now:** LLMs use citation mentions as authority signals. More mentions = more important in AI overviews.

---

## Step 3: Press Release Distribution

Press releases are the fastest way to build a large number of referring domains quickly.

**What to do:**
1. Write a newsworthy release about the brand launch, product, or milestone
2. Include links to homepage + key internal pages
3. Distribute via a press release service

**Budget options:**
- Fiverr or Legiit — as low as $5 per release
- ABNewswire

**Premium option:**
- Randy the News Guy (thenewsguy.com) — AP News, Yahoo News placement, high-quality domains

**Three strategic advantages:**
1. **Spike of referring domains** — Google expects this from press releases, so it won't flag as spam. This creates cover to build other links simultaneously.
2. **Page one rankings** — Press releases themselves can rank for low-competition and local keywords (parasite SEO).
3. **AI Overview training** — Press releases are frequently cited as sources in Google AI overviews. Possible to dominate AI overviews with just press releases.

---

## Step 4: Donation Links

Sponsor a website in exchange for a dofollow backlink. Overlooked and powerful.

**Types:**
- **Local:** Sports clubs, churches, community organizations
- **Public donor pages:** OSS projects, software foundations
  - Example: linuxmint.com/donors.php — donate, get a powerful dofollow link

**Pros:** High authority, dofollow, few competitors have them
**Cons:** Some require ongoing monthly payments

**Strategy:** Find 5-10 donation pages in relevant niches. Budget $50-200/month total.

---

## Step 5: Cloud Links

Static HTML pages uploaded to subdomains of major cloud platforms. These inherit massive domain authority from the root domain (DA 90+).

**Platforms (23+ via YACSS):**
- Google Cloud, AWS, Azure, Digital Ocean, Backblaze, Wasabi, Linode, Vultr, Oracle, GitHub Pages, Netlify, Cloudflare R2, Bunny CDN, OVH, Contabo, and more

**How to build:**
1. Create a simple HTML page with relevant content about your business/niche
2. Upload to multiple cloud platform subdomains
3. Interlink the cloud pages with each other
4. Point links from cloud pages to your main category/landing pages

**Tool:** YACSS (yacss.site) — automates creation and deployment across all 23+ cloud platforms

**Strategy:** Build 10-20 cloud links. Point them at category pages, not just homepage. Interlink them for compounding authority.

## Step 6: Manual Profile Links

Free profile pages on platforms like about.me, linktr.ee, and similar services. Mix of dofollow and nofollow.

**How to find opportunities:**
- Ask ChatGPT: "Give me a list of 30 links that are similar to about.me"
- Build a spreadsheet of working platforms
- Aim for 2-3 new profile links per day

**Rules:**
- Interlink profiles with each other
- Use relevant entities/keywords in profile content
- Keep descriptions varied — don't copy-paste the same bio everywhere
- Track which ones are indexed in Google

**Paid shortcut:** Jesper Nissen sells a vetted list of 103 link opportunities for $99 (jespernissen.com/product/103-links-list/)

## Step 7: Guest Posts / Paid Placements

Do this LAST — after the base is built. Scale link building with paid placements on authoritative sites.

**Marketplaces:**
- Bazoom.com — user-friendly, good competitor analysis
- Presswhiz
- Fiverr / Legiit (search "guest post")

**How it works:**
1. Choose a site with relevant audience and good domain authority
2. Write (or commission) an article with a contextual link to your site
3. Article gets published on the target site with your backlink

**Budget warning:** Gets expensive fast. Reserve for high-value pages that need extra push.

## Execution Priority

```
Week 1:
  Day 1-2:  GBP setup + social profiles (Steps 0-1)
  Day 3-4:  Citations (Step 2) — order on Fiverr/Legiit
  Day 5:    Press release draft + distribution (Step 3)

Week 2:
  Day 1-2:  Donation links research + placement (Step 4)
  Day 3-4:  Cloud links build (Step 5)
  Day 5:    Manual profile links start (Step 6)

Ongoing:
  2-3 manual profile links per day (Step 6)
  Guest posts as budget allows (Step 7)
```

## Quick Reference Checklist

When starting link building for a new website, verify:

- [ ] GBP created with full info + all social URLs
- [ ] 7 core social profiles built + cross-linked
- [ ] Citations ordered (Fiverr/Legiit)
- [ ] Press release written and distributed
- [ ] 5-10 donation links secured
- [ ] 10-20 cloud links deployed
- [ ] Manual profile links — building 2-3/day
- [ ] Guest posts — scaling as budget allows

## Key Principles

1. **Order matters.** Social profiles and citations establish legitimacy before heavier link building.
2. **Press releases create cover.** The referral domain spike from a press release masks other link building activity.
3. **Consistency beats intensity.** 2-3 manual links/day over months > 100 links in one day.
4. **Interlink everything.** Cloud links link to each other. Profile links link to each other. The network compounds authority.
5. **AI overviews are the new frontier.** Citations and press releases train LLMs to recognize your brand as authoritative.
