# Platform Formatting

Quick reference for formatting content per platform. Load this skill before posting to any platform.

## Discord

- Short messages (under 2000 chars ideal)
- `**bold**` for emphasis
- `- ` bullets for lists
- `<links>` or plain URLs (never wrap in backticks — breaks clickability)
- No tables, no headers in short messages
- Use `<callout>` blocks for important notices
- Markdown links: `[label](url)` OK

## WhatsApp

- `*bold*` (single asterisk, NOT `**`)
- No `**` double asterisks
- No `#` headers
- 2-3 line paragraphs max
- `_italic_` with single underscores
- `~strikethrough~` with single tildes

## X (Twitter)

- 280 character limit per post
- Threads for longer content (number each post 1/N)
- No markdown — plain text only
- Use line breaks for readability
- Media: images, videos, GIFs attach to posts

## LinkedIn

- Longer-form posts OK (3000 char limit)
- No markdown rendering — use unicode bullets (•, ▪)
- Line breaks for structure
- Hashtags at the end (3-5 max)

## Universal Rules

- No filler words ("I wanted to reach out...", "I hope this finds you well...")
- Be direct and concise
- No markdown tables in chat platforms
- Match the conversation energy of the platform
- URLs as plain text or markdown links, never in code blocks
- Keep paragraphs short (2-3 sentences max)
