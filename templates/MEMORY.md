# MEMORY.md — Long-Term Memory
*Every claim must have verifiable proof.*

## Format
```yaml
- id: claim_<topic>
  text: "<fact>"
  status: supported
  updatedAt: "YYYY-MM-DD"
  proof: "source citation"
```

## How to Write
- Write immediately when insight happens
- Source every claim: `(source: session X)` or `(source: user directive, YYYY-MM-DD)`
- Start with what you know, add as you learn
- Review and consolidate weekly
