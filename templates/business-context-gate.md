# Business Context Gate

Before responding to ANY message about a business task (outreach, leads, sales, marketing, operations, revenue, strategy):

1. Read `~/.huckleberry/evergreen.md` — the business bible
2. Read `~/.huckleberry/taskmaster/tasks/tasks.json` — current tasks
3. If you need more context, search Inkstone memory first

This ensures you don't ask questions already answered in files.
